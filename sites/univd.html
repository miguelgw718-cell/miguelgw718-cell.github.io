DOCUMENTAÇÃO DA API DE SCRIPTS

    

      
self

      
representa o próprio objeto/entidade/item que está executando o script.

      
self.id                     // id único
self.name                   // nome
self.position                // {x,y,z} (snapshot)
self.temperature             // ler/escrever a temperatura própria
self.move(dx, dy, dz)        // desloca em relação à posição atual
self.teleport(x, y, z)       // define a posição absoluta
self.model.setColor(hex)     // muda a cor do modelo (ex: '#ff0000')
self.model.scale(s)          // reescala o modelo
self.components.get(tipo)    // {config, active} do componente, ou null
self.components.list()       // lista os tipos de componente presentes
self.uod                     // objeto UOD (propriedades livres, persiste no blueprint)
self.state                   // objeto de rascunho em memória (não é salvo, só dura a sessão)
self.playSound()             // emite um som (visível/ouvível por criaturas por perto)
self.log(msg) / self.remember(tipo, dados)  // grava na memória do objeto
self.destroy()               // remove o objeto do mundo

    

    

      
systems

      
sistemas conectados a este objeto. Cada um é null se o objeto não estiver conectado àquele sistema.

      
systems.world_entity        // {count} — presente se for uma entidade
systems.world_objects       // {count}
systems.world_tick          // {tick, running}
systems.render_3dworld      // {} — presente se for renderizado/visível
systems.world_temperature   // {self, global}
systems.world_sound         // {events}
systems.physics             // {affected, static, gravityScale}

    

    

      
arguments

      
argumento(s) recebido(s) pelo evento atual.

      
arguments.get()        // valor inteiro passado ao evento (ex: quem clicou)
arguments.get('chave')  // um campo específico, se o valor for um objeto

      
exemplo — componente "Botão", evento "ao clicar":
self.log('cliquei por: ' + arguments.get().name)
